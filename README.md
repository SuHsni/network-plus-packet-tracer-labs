# Network+ Packet Tracer Labs

Hands-on networking labs created with **Cisco Packet Tracer** while studying Network+ concepts.

The goal of this repository is to build, configure, test, and document small networking scenarios based on fundamental networking concepts.

## Tools

- Cisco Packet Tracer
- GitHub
- Basic networking concepts

## Topics Covered

- LAN fundamentals
- IPv4 addressing
- Subnetting
- Switching
- Routing
- Default Gateway
- Static Routing
- DHCP
- VLANs
- Inter-VLAN Routing
- DNS
- Web Servers
- Network troubleshooting

## Lab Structure

Each lab contains:

- Packet Tracer `.pkt` file
- Lab documentation
- Network topology
- IP addressing information
- Configuration details
- Connectivity tests
- Expected results

## Learning Goals

This repository is a hands-on practice project for understanding fundamental networking concepts and developing practical troubleshooting skills.
